# R.S.S.

정보국 컨셉의 기밀 기록 관리 데스크톱 앱 (Windows `.exe`).

## 다운로드

항상 최신 버전으로 연결되는 링크입니다. (저장소 이름 끝의 점 `.` 까지 주소에 포함되어야 열립니다)

- 설치형: https://github.com/TheFirstTwistedKing/R.S.S./releases/latest/download/RSS-Setup.exe
- 포터블: https://github.com/TheFirstTwistedKing/R.S.S./releases/latest/download/RSS-Portable.exe
- 릴리즈 페이지: https://github.com/TheFirstTwistedKing/R.S.S./releases/latest

| 파일 | 설명 |
|---|---|
| `RSS-Setup.exe` | 설치형. 바탕화면·시작 메뉴에 R.S.S. 아이콘 생성 |
| `RSS-Portable.exe` | 설치 없이 더블클릭으로 실행 |

코드 서명 인증서가 없어서 처음 실행할 때 SmartScreen 경고가 나올 수 있습니다 → **추가 정보 → 실행**.

## 화면

- **잠금 인트로**: 실행할 때마다 화면이 켜지는 연출 뒤 홀로그램 문장, 회전하는 지구본, 숫자 자판이 나옵니다. 첫 실행 때 4~8자리 코드를 정합니다.
- **메인**: 화면 전체가 테두리 없는 터미널 대화창이고, 아래쪽 가로 띠에 시스템 로그가 쌓입니다. 배경에는 이진수가 희미하게 흘러내리고, 노이즈가 섞인 스캔라인이 위에서 내려옵니다.
- **창 열기**: Control 이 창을 열 때 이진수 · 한글 · 영어 · 일본어 · 중국어 · 히브리어가 섞여 쏟아진 뒤 창이 나타납니다.
- **봉인 문서**: `I Archi(이아키) 행성` 은 미완성 · 승인 대기 문서입니다. 아카이브에서 열면 접근 불가, Control 에게 물어도 승인이 없어 열람할 수 없습니다.
- **소리**: 항상 켜짐. 타자음(실제로 쓰거나 지울 때만), 마우스 클릭음.

## Control 학습

Control 은 사용자가 가르친 말을 기억합니다. (인터넷 · 외부 AI 없이 앱 안에서만 동작)

| 이렇게 말하면 | 하는 일 |
|---|---|
| `현황판 이라고 하면 아카이브 현황 보여줘` | "현황판" 을 그 명령으로 기억 |
| `블루베리는 아카이브 열어 라는 뜻이야` | 위와 같음 |
| (못 알아들은 말 바로 뒤) `아카이브 열어 라는 뜻이야` | 방금 그 말을 그 뜻으로 기억 |
| (못 알아들은 말 뒤에 다르게 말해서 처리되면) `응` | 처음 말도 같은 뜻으로 기억 |
| `나를 대장이라고 불러` | 호칭 기억 (`원래대로 불러` 로 되돌림) |
| `학습 목록` · `학습 삭제 <번호>` · `학습 초기화` | 배운 말 관리 |
| `학습 내보내기` · `학습 가져오기` | 다른 PC 로 옮기기 |

- 배운 내용은 보관소 안에 암호화되어 저장되고, 암호화 백업에도 함께 들어갑니다.
- 오타나 띄어쓰기가 조금 달라도 비슷한 배운 말이 있으면 그것으로 알아듣습니다.
- **다른 PC 에 적용**: `학습 내보내기` 로 공유 코드(숫자 4~8자리)로 잠근 `.rssbrain` 파일을 만들고, 다른 PC 에서 `학습 가져오기` 로 합칩니다(그 PC 의 기존 학습은 지우지 않음).
- **모든 PC 에 기본으로 넣기**: 규칙을 `src/js/learned.js` 에 적어 새 버전을 배포하면 모든 설치본에 들어갑니다.

## R.S.S. Mobile (안드로이드 앱)

**다운로드: https://github.com/TheFirstTwistedKing/R.S.S./releases/download/mobile/RSS-Mobile.apk**
휴대폰에서 위 주소로 APK 를 받아 설치합니다. 처음 한 번은 "출처를 알 수 없는 앱 설치 허용" 을 켜야 합니다(Play 스토어 앱이 아님). 새 버전은 같은 주소에서 받아 덮어 설치하면 지갑 · 기록이 유지됩니다. (아이폰은 APK 를 설치할 수 없음)

- 접속: R.S.S. 처럼 숫자 4~8자리 접속 코드 (처음엔 정하고, 다음부터 입력) · 앱을 열 때마다 잠금 화면부터
- 처음 접속하면 **R.S.S. Mobile Simulation** 과 함께 지갑에 **50,000,000 LEVC** 지급 (한 번만)
- **시장**: 6개국 26개 기업 주식. 주가는 각 나라 화폐, 사고팔 때 그 순간의 환율로 LEVC 와 바뀜 (환율 변동도 손익에 반영)

| 나라 (화폐) | 기업 |
|---|---|
| 버믹쿠루시아 (VEC) | **천공월아민간군사기업** · 아크 공방기업 · 홍색산업 · 이한영의 부동산 |
| 레스렉시온 (RTC) | 레벨리아의 공방 · **C.O.R.E.** · 선형은행 · 막강건설사 |
| 아스트랄리스 (SD) | **STAR DEFENCE PROJECT** · 별빛 공방기업 · 환성감정소 · C.R.O.W.N. |
| 추풍 (DEM) | **오색단풍** · 켄의 복사점 · 단풍건설사 · 료코의 공방기업 |
| 엘라렌 (MEC) | **엘 항공사** · 성민물류 · **라오스무역** · 에스터 공방기업 · 환서조선 · 그레이스 물류산업 |
| 은월 (EOM) | **메모리 디벨롭 스튜디오** · 달 관광사 · 월광 공방기업 · 블러디어스 공방기업 |

  굵은 7곳은 고위험: 주가가 높고, 크게 오르고 크게 떨어짐 (하루 변동성 약 9~10%, 수십 % 급등락 소식)
- **보유**: 산 주식마다 보유 수량 · 평균 매수가 · 현재가(나라 화폐) · 평가액 · 손익(LEVC), 진행 중인 투자와 투자 결과
- **기업 투자 요청**: 앱이 열려 있는 동안 5초마다 1% 확률로, 보유한 기업 중 한 곳이 투자를 요청 (한 번 오면 150초 동안 새 요청 없음). 금액은 5,000만 LEVC 이상을 그 기업 나라의 화폐로 제시, 60초 안에 투자/거절. 투자하면 60초 뒤 결과: 1억 LEVC 를 중심으로 오르면 1억~2억, 떨어지면 0~1억 LEVC 를 돌려받음 (확률은 화면에 표시하지 않음). 오르면 '연구 성공' 으로 그 기업 주가가 크게 뜀 (일반 +35~70%, 고위험 +60~150%)
- **일하기 (R.S.S. 장치 활성화)**: 전선 10개를 색과 도형 문양이 모두 같은 연결부 10개에 연결 → 톱니바퀴를 시계 방향으로 두 바퀴 → **50,000,000 LEVC**. 하루 한 번, 휴대폰 시각 기준 오전 12:00(자정)에 다시 열림
- **연구 실패**: 투자 결과가 떨어지면 그 기업 주가도 급락 (일반 −15~30%, 고위험 −30~55%)
- **상점**: LEVC 를 각 나라 화폐로 환전(수수료 0.5%, 반대로도 가능) → 그 나라 화폐로만 살 수 있는 특산품(나라마다 4가지) 구매 · 소장품으로 남음
- **기업 독점**: 기업 상세에서 주가 × 150,000 (그 나라 화폐, 그 순간 환율로 LEVC 지불). 독점한 기업은 앱이 열려 있는 동안 1분마다 독점 가치의 0.1% 를 그 나라 화폐로 지급
- **일하기 3가지** (각각 하루 한 번, 자정 초기화): 장치 활성화 50,000,000 · 암호 해독 30,000,000 (1~6 숫자 4자리를 8번 안에) · 신호 동조 30,000,000 (파형 맞추고 고정)
- **기록 · 업적**: 최고 총 자산, 연구 성공/실패, 거래 횟수, 장치 활성화 연속 일수, 일하기 보수, 독점 수익 · 업적 18가지
- 시장 시간은 60배속, 0.25초마다 가격, 3초마다 봉 하나. 앱이 꺼져 있는 동안 시장도 멈춤
- 지갑 · 보유 주식 · 기록은 그 휴대폰 안에만 암호화되어 저장. **R.S.S. 컴퓨터 앱에는 아무 영향이 없음**
- 파일: `mobile/` (화면 · 기능) + `android-app/` (안드로이드 포장, Capacitor). main 에 병합되면 GitHub Actions 가 APK 를 만들어 Releases 의 `mobile` 항목에 올림
- 서명: 매번 같은 서명이 되도록 `android-app/debug.keystore`(테스트용 키)를 씀

## 아카이브는 열람 전용

이 앱은 세계관 열람용입니다. 앱 안에서는 문서를 만들거나 고치거나 지울 수 없습니다 (Control 에게 요청해도 거절합니다).
세계관 문서는 `src/js/lore.js` 에 적힌 것만 아카이브 · 관계도 · 타임라인에 나옵니다. 파일 맨 위에 형식 설명이 있습니다.
문서를 추가하거나 고친 뒤 `package.json` 의 `version` 을 올려 `main` 에 병합하면 새 설치 파일이 배포됩니다.

## Control · Apex

| AI | 역할 |
|---|---|
| **Control** | 사용자와 대화하는 AI. 요청을 받아 Apex 에게 일을 시킵니다. |
| **Apex** | 정보 관리 전용 AI. 아카이브를 조회하고 봉인 문서 접근을 판단합니다. |

요청 흐름: 사용자 → Control → (Apex 에게 지시) → Apex 가 아카이브를 조회해 보고 → Control 이 사용자에게 전달

## 메신저 (`msg`)

- **같은 네트워크(같은 공유기 · 와이파이)** 에 있는 R.S.S. 사용자끼리 대화합니다. 서버가 필요 없습니다.
- 호출부호(닉네임)와 **채널 코드**를 넣고 접속합니다. 같은 채널 코드를 넣은 사람끼리만 내용을 읽을 수 있습니다 (AES-256-GCM 암호화).
- 대화 내용은 저장되지 않습니다. 창을 닫거나 잠그면 채널에서 나갑니다.
- 처음 접속할 때 Windows 방화벽 창이 뜨면 **허용**을 눌러야 다른 PC 와 연결됩니다.
- 다른 네트워크(인터넷 너머) 사람과 대화하려면 중계 서버가 필요합니다 (아직 없음).

Control·Apex 는 인터넷이나 외부 AI 를 쓰지 않는 앱 안의 규칙 기반 대화입니다. 대사는 `src/js/dialogue.js` 한 파일에 모여 있어 그 파일만 고치면 바뀝니다.

모든 기록과 로그는 접속 코드로 AES-256-GCM 암호화되어 `%APPDATA%\R.S.S.\rss-vault.json` 에만 저장됩니다. 코드를 잊으면 복구할 수 없습니다.

## 개발

```bash
npm install
npm start          # 앱 실행
npm run dist       # Windows exe 빌드 (Windows에서 실행)
```

`main` 으로 가는 PR 은 Windows 빌드만 확인하고, `main` 에 병합되면 GitHub Actions가 exe를 빌드해 `package.json` 버전으로 Release(`v3.4.0` 등)에 올립니다. 새 릴리즈를 만들려면 `version` 을 올려서 병합하세요.

아이콘은 `src/js/emblem.js` 벡터 문장으로 만들어집니다. 문장을 바꿨다면 `node scripts/make-icon.js` (playwright, png-to-ico 필요)로 `build/icon.ico`를 다시 생성합니다.
